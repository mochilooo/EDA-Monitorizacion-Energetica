# Monitorización inteligente del consumo energético residencial

**Proyecto de Data Science · Análisis Exploratorio de Datos (EDA)**

## 1. Descripción del proyecto

Este proyecto estudia el comportamiento del consumo energético en viviendas residenciales y su posible relación con las condiciones ambientales interiores y exteriores.

Se analizarán variables como la temperatura, la humedad relativa y el consumo de electricidad y gas, con el objetivo de identificar patrones y diferencias entre hogares.

## 2. Objetivo

Explorar la relación entre las condiciones ambientales y el consumo energético residencial, así como las diferencias observables entre viviendas.

## 3. Fuente de datos

Dataset principal: **MODIF-HABIT**.

- Procedencia: viviendas residenciales de Madrid, España.
- Número de viviendas: 20.
- Variables: temperatura interior, humedad relativa, electricidad y gas.
- Frecuencia declarada: 15 minutos.
- Licencia: CC BY 4.0.

Repositorio: https://doi.org/10.5281/zenodo.20367908
